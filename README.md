# danish-portfolio

Personal portfolio website — a modern, animated single-page landing page built with vanilla **HTML**, **CSS** and **JavaScript**.

## ✨ Features

- Animated gradient hero with typing effect
- Scroll-reveal animations throughout
- Animated skill bars and stat counters
- Glassmorphism cards with hover interactions
- Fully responsive + mobile menu
- Zero dependencies, zero build step

## 🚀 Run it

Just open `index.html` in a browser — or serve it locally:

```bash
npx serve .
```

## 📁 Structure

```
├── index.html   # Page markup
├── styles.css   # All styling & animations
└── script.js    # Typing effect, reveal-on-scroll, counters, nav
```

## 📝 Customise

Search the files for `PLACEHOLDER` comments and `[Your City]` / `example.com` values, and replace them with your real details — bio, projects, email and social links.
